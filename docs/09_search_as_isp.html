Notebook 09: Search as an Indivisible Process¶

Goal: Read Grover's search algorithm (Nielsen & Chuang ch. 6) as an indivisible stochastic process on the database indices, and find where its speedup lives in Barandes's terms.

By the end of this notebook you will be able to:

  • Show that a phase oracle is invisible to Γ, that the marked item first appears in Γ through indivisibility across two queries, and why the standard bit oracle, which Γ can see, does not change the picture
  • Show that the speedup needs a query-free preparation step, and that search from a bare configuration does worse than classical search
  • Show that Grover's search moves the probability column along a geodesic on the probability sphere
  • Measure how records (division events) during the search erode the √N speedup, and why with full records a longer search does worse
  • Check that Farhi–Gutmann continuous-time search approaches the speed limit $T \ge \arccos(1/\sqrt N)/\nu$, with ν read off Γ, and see that a diagonal term leaves ν unchanged but lets the column move faster than ν, so the bound's premise belongs to this Hamiltonian, not to every process with the same ν

Sources. "Paper 1, 2, 3" are Jacob A. Barandes's papers:

  • Paper 1: "The Stochastic-Quantum Correspondence", arXiv:2302.10778 (Philosophy of Physics 3(1), 8, 2025).
  • Paper 2: "The Stochastic-Quantum Theorem", arXiv:2309.03085.
  • Paper 3: "Quantum Systems as Indivisible Stochastic Processes", arXiv:2507.21192 (Stud. Hist. Phil. Sci. 119, 102213, 2026).

Other works are cited in the text by author and arXiv number or journal reference; the full list is in REFERENCES.md.

1. The Oracle Is Invisible to Γ¶

Configurations are the $N$ database indices; one of them, $w$, is marked. Grover's iterate is $G = D\,O$ with

$$O = I - 2|w\rangle\langle w|, \qquad D = 2|s\rangle\langle s| - I, \qquad |s\rangle = \tfrac{1}{\sqrt N}\textstyle\sum_j |j\rangle .$$

Every unitary $U$ defines the transition matrix $\Gamma(U)_{ij} = |U_{ij}|^2$. The oracle only flips a sign, so $\Gamma(O) = I$. One full query from a configuration is also blind to $w$: $|(DO)_{ij}| = |D_{ij}|$, so $\Gamma(DO) = \Gamma(D)$. Started from a configuration, the marked item enters Γ only after two queries, and only because $\Gamma((DO)^2) \neq \Gamma(DO)\,\Gamma(DO)$: through indivisibility. With the Walsh–Hadamard step $W$ first (section 2) it appears after one query, since $\Gamma(DOW) \neq X\,\Gamma(W)$ for every stochastic $X$ ($\Gamma(W)$ has identical columns, $\Gamma(DOW)$ does not): again through indivisibility.

This depends on the encoding. The standard bit oracle $|x, b\rangle \mapsto |x, b \oplus [x = w]\rangle$, with an ancilla bit as part of the configuration, is a permutation that depends on $w$, so Γ sees it. Grover turns it into the phase oracle by preparing the ancilla in $|-\rangle$.

def grover_ops(N, w):
    s = np.full(N, 1 / np.sqrt(N))
    O = np.eye(N); O[w, w] = -1
    D = 2 * np.outer(s, s) - np.eye(N)
    return O, D, s

2. The Speedup Needs a Preparation Step¶

Start in configuration $0$. The circuit applies the Walsh–Hadamard transform $W = H^{\otimes n}$ (no query) and then $k$ Grover iterates, so the process is $\Gamma(G^k W)$ and the success probability is $\Gamma_{w \leftarrow 0}(G^k W)$. Without $W$ the same queries act on a bare configuration. The fair baseline is a classical searcher, who checks one index per query and after $k$ queries has found $w$ with probability $k/N$.

The code uses $\theta = \arcsin(1/\sqrt N)$, the angle between $|s\rangle$ and the uniform superposition of the unmarked indices. Each Grover iterate rotates the state by $2\theta$, and the success probability after $k$ iterates is $\sin^2((2k+1)\theta)$. Nielsen & Chuang use θ for the full rotation per iteration, defined by $\cos(\theta/2) = \sqrt{(N-M)/N}$ (§6.1.3), so this notebook's θ is their $\theta/2$ (with $M = 1$ marked item), and their "rotation by θ" is this notebook's $2\theta$ per query.

3. Grover's Search Is a Geodesic on the Probability Sphere¶

As in notebook 07, map each probability column $p$ to $\sqrt p$ on the unit sphere and measure distances by the Bhattacharyya angle $\arccos\sum_i\sqrt{p_i q_i}$. Column 0 of $\Gamma(G^k W)$ starts at the uniform point and should end near $e_w$.

The evidence for the geodesic is the printed ratio path length / direct angle. The right-hand plot only displays the route: in $(\sqrt{1-P_w}, \sqrt{P_w})$ coordinates every distribution lands on the unit circle, so the plot alone proves nothing.

def bh_angle(p, q):
    return np.arccos(np.clip(np.sqrt(p) @ np.sqrt(q), -1, 1))

4. Records During the Search¶

After every query, an environment records the index imperfectly: notebook 06's records, which notebook 08 identified as phase damping. Off-diagonal elements of ρ are multiplied by $c = 1 - \varepsilon$. $\varepsilon = 0$ is Grover; $\varepsilon = 1$ is a full record (a division event) after every query, which makes the process Markov with step $\Gamma(D)\,\Gamma(O) = \Gamma(D)$.

Cost: expected queries with restarts, $T = \min_k k / P_w(k)$.

def search_with_records(N, eps, w=0):
    s = np.full(N, 1 / np.sqrt(N))
    o = np.ones(N); o[w] = -1
    rho = np.outer(s, s)
    best, P, k = np.inf, [], 0
    while k < best and k < 50 * N:
        k += 1
        rho = rho * np.outer(o, o)                          # oracle
        Dr = 2 * np.outer(s, s @ rho) - rho                 # diffusion, left
        rho = 2 * np.outer(Dr @ s, s) - Dr                  # diffusion, right
        d = np.diag(rho).copy()
        rho = (1 - eps) * rho; rho[np.diag_indices(N)] = d  # record
        P.append(rho[w, w])
        best = min(best, k / rho[w, w])
    return best, np.array(P)

5. Continuous-Time Search and Its Speed Limit¶

Farhi–Gutmann search: $H = |w\rangle\langle w| + |s\rangle\langle s|$ (frequency units), started in $|s\rangle$; it reaches $|w\rangle$ at $T = \pi\sqrt N/2$. Read the agility $\nu_j = \sqrt{-\tfrac12\ddot\Gamma_{jj}(0)}$ off Γ alone, as in notebook 07, and compare $T$ with

$$T \;\ge\; \frac{\arccos(1/\sqrt N)}{\nu}$$

(start and target overlap by $1/\sqrt N$), and with the naive form $T\nu \ge \pi/2$. The bound rests on the column moving no faster than ν. That holds for this Hamiltonian; the end of this section shows a diagonal term that leaves ν unchanged but lets the column move faster than ν.

In [6]:
rows = []
for N in [4, 16, 64, 256, 1024]:
    x = 1 / np.sqrt(N)
    s = np.full(N, x); e_w = np.zeros(N); e_w[0] = 1
    H = np.outer(e_w, e_w) + np.outer(s, s)
    ev, V = np.linalg.eigh(H)
    ts = np.linspace(0, 1.2 * np.pi / (2 * x), 4001)
    P = np.abs(V @ (np.exp(-1j * np.outer(ev, ts)) * (V.T @ s)[:, None])) ** 2
    T_hit = ts[np.argmax(P[0])]
    h = 1e-4
    nu = np.sqrt(np.clip(-(np.diag(Gam(expm(-1j * H * h))) - 1) / h ** 2, 0, None))
    dP = np.gradient(P, ts, axis=1)
    with np.errstate(divide='ignore', invalid='ignore'):
        speed = 0.5 * np.sqrt(np.where(P > 1e-14, dP ** 2 / P, 0).sum(axis=0))
    m = ts <= T_hit
    rows.append((N, T_hit, nu.min(), nu.max(), speed[m][1:-1].max() / nu[1],

The limit belongs to this Hamiltonian, not to Γ¶

"Column speed ≤ ν" is notebook 07's inequality for a start in a configuration. Search starts in $|s\rangle$, and there the inequality holds only because the Farhi–Gutmann Hamiltonian is so symmetric. Add a diagonal term, $+a$ on odd unmarked indices and $-a$ on even ones. The agility ν read off Γ does not change, because $\nu_j^2 = \sum_{i\ne j}|H_{ij}|^2$ involves only off-diagonal entries. The column's speed does.

N = 16
s = np.full(N, 1 / np.sqrt(N)); e_w = np.zeros(N); e_w[0] = 1
ts = np.linspace(0, 8, 8001)
for a in [0.0, 0.5, 1.0, 2.0]:
    pert = np.zeros(N); pert[1::2] = a; pert[2::2] = -a          # ±a on the unmarked indices
    H = np.outer(e_w, e_w) + np.outer(s, s) + np.diag(pert)
    h = 1e-4
    nu = np.sqrt(np.clip(-(np.diag(Gam(expm(-1j * H * h))) - 1) / h ** 2, 0, None)).max()
    ev, V = np.linalg.eigh(H)
    P = np.abs(V @ (np.exp(-1j * np.outer(ev, ts)) * (V.T @ s)[:, None])) ** 2
    angle = np.arccos(np.clip(np.sqrt(P[:, 0]) @ np.sqrt(P), -1, 1))      # Bhattacharyya angle from the start
    dP = np.gradient(P, ts, axis=1)
    with np.errstate(divide='ignore', invalid='ignore'):
        speed = 0.5 * np.sqrt(np.where(P > 1e-14, dP ** 2 / P, 0).sum(axis=0))
    ratio = angle[1:] / (nu * ts[1:])
    i = np.argmax(ratio)
    print(f'a = {a}:  ν from Γ = {nu:.5f}   max column speed / ν = {speed.max() / nu:.4f}'
          f'   max angle travelled / (ν t) = {ratio[i]:.4f} (at t = {ts[i + 1]:.2f})')

Summary¶

  • A phase oracle is invisible to Γ. $\Gamma(O) = I$ and $\Gamma(DO) = \Gamma(D)$. Started from a configuration, the marked item first appears in $\Gamma((DO)^2)$, which differs from $\Gamma(DO)^2$ (with the Walsh–Hadamard step first it appears after one query, since no stochastic step maps $\Gamma(W)$ to $\Gamma(DOW)$): query information reaches the configurations only through indivisibility. A bit oracle (ancilla in the configuration) is a Γ-visible permutation; what Γ cannot see, in either encoding, is what the query-free steps do with the phases.
  • Preparation is essential. From a bare configuration the queries never lift $\Gamma_{w\leftarrow 0}$ above $1/(N-1)$ ($1.01/N$ at $N = 64$), while a classical searcher has found $w$ with probability $k/N$ after $k$ queries: bare-start search is worse than classical. The query-free Walsh–Hadamard step makes the speedup possible.
  • Geodesic. The probability column moves along the great circle from uniform to $e_w$, at exactly $2\theta = 2\arcsin(1/\sqrt N)$ per query (N&C's rotation angle θ), for as long as $(2k+1)\theta \le \pi/2$.
  • Records. Phase damping of strength ε after each query erodes the speedup once $\varepsilon\sqrt N \gtrsim 1$; the scaling exponent goes from 0.5 to 1. With full records the step is $\Gamma(D)$, independent of $w$, and the success probability decays back toward $1/N$.
  • Speed limit, for this Hamiltonian. Farhi–Gutmann search moves the column along a geodesic, reaching speed ν at its peak (it starts from rest), and its hitting time approaches $\arccos(1/\sqrt N)/\nu$ with ν read off Γ (2% above it at $N = 1024$). The naive form $T\nu \ge \pi/2$ does not apply because the start is not a configuration and the target is not orthogonal to it. The bound is not a Γ-only law: a diagonal term leaves ν unchanged but lets the column move about twice as fast as ν (2.05 ν at $a = 1$, $N = 16$).

Caveats: a single marked item, synthetic noise in the index basis only, cost measured with restarts, and the $\varepsilon\sqrt N$ collapse is approximate (a slow residual drift with $N$ remains).

Prior work: the invisibility of a phase oracle restates standard quantum mechanics in Γ language. Search from an arbitrary start, including a bare configuration, is Biham et al. (1999); Grover's search as a geodesic is Miyake and Wadati (2001, Phys. Rev. A 64, 042317) and Alvarez and Gómez (1999, preprint). Shenvi, Brown & Whaley (2003) show that a random oracle phase error must shrink as $O(N^{-1/4})$ (§II), i.e. a per-query coherence loss of order $N^{-1/2}$: the same scale as the $\varepsilon\sqrt N \lesssim 1$ found here, for a different noise model. The arccos bound is the Mandelstam–Tamm bound (non-orthogonal form) for the start $|s\rangle$; ν can stand in for the energy spread of $|s\rangle$ only because the two are equal for the Farhi–Gutmann Hamiltonian.
