1. The Divisibility Condition¶

A process with transition matrices $\{T(t_i, t_j)\}$ is divisible if, for every triple of times $t_1 < t_2 < t_3$, there is a valid stochastic matrix $T(t_3, t_2)$ — all entries ≥ 0, columns summing to 1 — such that:

$$T(t_3, t_1) = T(t_3, t_2) \cdot T(t_2, t_1)$$

When $T(t_2, t_1)$ is invertible there is exactly one candidate, found by solving for it:

$$T(t_3, t_2) = T(t_3, t_1) \cdot T(t_2, t_1)^{-1}$$

and the process is divisible at that triple exactly when this matrix is a valid stochastic matrix. When $T(t_2, t_1)$ is singular there is no inverse, and this shortcut cannot decide the question.

Asking this for every triple is stronger in form than Barandes's own condition (Paper 1, eq. 6), which conditions on the initial time only: for each $t > t' > t_0$, is there a stochastic $\tilde\Gamma(t \leftarrow t')$ with $\Gamma(t \leftarrow t_0) = \tilde\Gamma(t \leftarrow t')\,\Gamma(t' \leftarrow t_0)$? The two agree when the matrices are invertible.

# Build a simple divisible process: three explicit steps
T1 = np.array([[0.8, 0.3], [0.2, 0.7]])
T2 = np.array([[0.7, 0.4], [0.3, 0.6]])
T3 = np.array([[0.9, 0.2], [0.1, 0.8]])

proc = StochasticProcess(
    states=["0", "1"],
    transitions=[T1, T2, T3],
    times=[0.0, 1.0, 2.0, 3.0]
)

result = check_divisibility(proc)
print("Divisible?", result["divisible"])
print("Failure mode:", result["failure_mode"])

2. Why Markov Chains Are Always Divisible¶

For a time-homogeneous continuous-time Markov chain with a valid generator $L$ (off-diagonal entries ≥ 0, columns summing to 0), $T(t) = e^{Lt}$. The composition law for matrix exponentials gives: $$e^{L(t_3-t_1)} = e^{L(t_3-t_2)} \cdot e^{L(t_2-t_1)}$$

This identity holds for any times — Markov chains are divisible by construction. The intermediate matrix is simply $T(t_3,t_2) = e^{L(t_3-t_2)}$, which is a valid stochastic matrix for every valid generator $L$.

L = np.array([[-0.5,  0.3],
              [ 0.5, -0.3]])

times = [0.0, 0.5, 1.2, 2.0, 3.5]
markov = make_markov_chain(2, L, times)

result = check_divisibility(markov)
sig = indivisibility_signature(markov)

print(f"Divisible: {result['divisible']}")
print(f"Indivisibility signature: {sig:.2e}  (should be ~0)")

Summary¶

  • Divisibility means the process can always be factored through any intermediate time
  • The intermediate matrix must be non-negative with columns summing to 1
  • Markov chains are always divisible — $T(t) = e^{Lt}$ guarantees it
