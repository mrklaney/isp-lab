Notebook 05: Interference From Indivisibility¶

Goal: Build a double-slit model as a genuine stochastic process, show that on this model interference and indivisibility appear together, and see exactly how far that link goes.

By the end of this notebook you will be able to:

  • Build the double slit as a unistochastic process on transverse modes
  • Test Barandes' divisibility condition on that same model, without matrix inversion
  • Show that the fringe pattern is the divisibility defect, entry for entry
  • Tune the coherence and watch interference and indivisibility vanish together on this model
  • Tell existential divisibility (some valid middle step exists) from matched divisibility (the process's own middle step composes), and see a completion where fringes and divisibility coexist

Sources. "Paper 1, 2, 3" are Jacob A. Barandes's papers:

  • Paper 1: "The Stochastic-Quantum Correspondence", arXiv:2302.10778 (Philosophy of Physics 3(1), 8, 2025).
  • Paper 2: "The Stochastic-Quantum Theorem", arXiv:2309.03085.
  • Paper 3: "Quantum Systems as Indivisible Stochastic Processes", arXiv:2507.21192 (Stud. Hist. Phil. Sci. 119, 102213, 2026).

Other works are cited in the text by author and arXiv number or journal reference; the full list is in REFERENCES.md.

1. The Double Slit as a Stochastic Process¶

Three times, one particle, n transverse modes:

t0  source  --U1-->  t1  slit plane  --U2-->  t2  screen

U1 sends the source into the balanced superposition of the two slits. U2 is the unitary DFT, which is Fraunhofer (far-field) propagation. Because U2 is unitary its columns are orthonormal, so the two slit amplitudes do not overlap and Born-rule probabilities normalise on their own.

The transition matrices are unistochastic, G[i,j] = |U[i,j]|^2:

matrix meaning
G(t1,t0) = abs(U1)^2 source to slits
G(t2,t1) = abs(U2)^2 slits to screen
G(t2,t0) = abs(U2 U1)^2 source to screen, coherent

The decohered alternative, a which-path measurement at the slits, replaces the last one with the product G(t2,t1) G(t1,t0). Whether those two agree is whether abs(U2)^2 works as the slit-to-screen step. Divisibility asks the broader question of whether any valid slit-to-screen matrix does (section 3).

2. Interference¶

The screen distribution for a particle emitted from the source is the source column of G(t2,t0). Coherent gives amplitudes-then-square; decohered gives probabilities-then-add.

3. Divisibility, Tested on This Model¶

Notebooks 02 and 03 test divisibility by solving G(t2,t1) = G(t2,t0) inv(G(t1,t0)) and looking for negative entries. That needs G(t1,t0) to be invertible, and here it never is.

If a unitary sends the source to the balanced superposition of slits A and B, then rows A and B of U1 each have entry 1/sqrt(2) in the source column. Orthonormality of the rows forces the Cauchy-Schwarz inequality on the remaining entries to be saturated, so those row tails must be proportional, which makes rows A and B of abs(U1)^2 identical. The matrix is rank-deficient for every balanced two-slit model. The inverse-based test is not inconclusive here; it is unavailable.

So test the condition the way Barandes states it: does any valid stochastic matrix G(t2,t1) satisfy G(t2,t0) = G(t2,t1) G(t1,t0)? That is a linear program, and needs no inverse. For two configurations, Pimenta (arXiv:2505.08785, §III.1) characterises divisibility geometrically, singular G(t1,t0) included; the LP handles any number of configurations.

4. The Fringe Pattern Is the Divisibility Defect¶

Define the defect matrix

D = G(t2,t0) - G(t2,t1) G(t1,t0)

which is zero exactly when the process composes classically through G(t2,t1) = abs(U2)^2. Its source column is the interference pattern. Not analogous to it, equal to it.

5. Interference and Indivisibility Together, on This Model¶

Dephasing the slit-plane density matrix by a factor c on its off-diagonal entries and propagating gives, for every input mode,

G_c(t2,t0) = (1 - c) G(t2,t1) G(t1,t0)  +  c abs(U2 U1)^2

so c = 1 is a fully coherent particle and c = 0 is a which-path measurement. Sweep c and measure both quantities on the same process.

In [7]:
coherences = np.linspace(0, 1, 21)
visibility, column_defect, divisible = [], [], []

for c in coherences:
    mc = double_slit_matrices(coherence=c)
    p = screen_distribution(mc)
    visibility.append(fringe_visibility(p))
    column_defect.append(np.abs(p - screen_distribution(mc, 'gamma_20_decohered')).sum())
    divisible.append(check_divisibility_lp(make_double_slit_process(coherence=c))['divisible'])

visibility = np.array(visibility)
column_defect = np.array(column_defect)
divisible = np.array(divisible)

print(f'visibility equals the coherence exactly: max error {np.abs(visibility - coherences).max():.2e}')
print(f'divisible only at c = {coherences[divisible]}')
print(f'interference present wherever indivisible: {np.all(visibility[~divisible] > 1e-12)}')
print(f'no interference wherever divisible:        {np.all(visibility[divisible] < 1e-12)}')

6. The Prediction Does Not Depend on the Arbitrary Part of the Model¶

Only the source column of U1 is physical. The remaining columns are an arbitrary orthonormal completion, needed because a process requires a full transition matrix. Vary that completion and check that nothing observable moves.

What this does and does not show. The screen distributions use only the physical source column, so they cannot change. The divisibility verdict uses the whole matrix. The source column on its own can always be matched by a valid intermediate step: give slits A and B the coherent screen distribution as their columns. So "indivisible" is a statement about the full process, and here it is confirmed for these five completions, not proved for all of them. Section 7 shows why that caveat matters.

7. A Completion Where the Two Come Apart¶

Sections 5 and 6 found interference and indivisibility together for every completion of U1 they tried. That is a property of those completions, not a law. Two different questions hide in the word "divisible":

  • Existential divisibility (Barandes's definition, Paper 1, eq. 6): does some valid stochastic G(t2,t1) satisfy G(t2,t0) = G(t2,t1) G(t1,t0)? The LP tests this.
  • Matched divisibility: does the process's own slit-to-screen matrix, G(t2,t1) = abs(U2)^2, compose with G(t1,t0)? That is D = 0 in section 4. Calvo (arXiv:2601.18720), Fig. 2, and Doukas (arXiv:2602.22095), footnote 9, use this notion.

Interference always breaks matched divisibility: the fringes are the source column of D. It need not break existential divisibility. Take n = 8, source 0, slits 3 and 5 (symmetric about the source on the ring of modes: A + B ≡ 2s mod n), the same DFT second stage, and complete U1 with a real block on {source, A, B} and the identity elsewhere:

$$U_1\big|_{\{0,3,5\}} = \begin{pmatrix} 0 & 1/\sqrt2 & -1/\sqrt2 \\ 1/\sqrt2 & -1/2 & -1/2 \\ 1/\sqrt2 & 1/2 & 1/2 \end{pmatrix}$$

Its source column is the same balanced slit preparation, so the fringes are the same kind as before.

In [10]:
from isp.double_slit import far_field_propagator
from isp.stochastic import PairwiseProcess

n8, s8, a8, b8 = 8, 0, 3, 5
r = 1 / np.sqrt(2)
block = np.array([[0, r, -r],
                  [r, -0.5, -0.5],
                  [r, 0.5, 0.5]])
U1s = np.eye(n8, dtype=complex)
U1s[np.ix_([s8, a8, b8], [s8, a8, b8])] = block
U2s = far_field_propagator(n8)
g10s, g21s = np.abs(U1s) ** 2, np.abs(U2s) ** 2
print('U1 unitary:', np.allclose(U1s.conj().T @ U1s, np.eye(n8)))
print()

for c in (0.0, 0.25, 0.5, 0.51, 0.75, 1.0):
    g20s = (1 - c) * g21s @ g10s + c * np.abs(U2s @ U1s) ** 2
    proc_s = PairwiseProcess(states=[str(i) for i in range(n8)], times=[0.0, 1.0, 2.0],
                             matrices={(0, 1): g10s, (1, 2): g21s, (0, 2): g20s})
    res = check_divisibility_lp(proc_s)
    print(f'c = {c:4.2f}:  visibility {fringe_visibility(g20s[:, s8]):.2f}   '
          f'existential: divisible {str(res["divisible"]):5s}   '
          f'matched: sum abs(D) = {np.abs(g20s - g21s @ g10s).sum():.2f}')

print()
lab = check_divisibility_lp(make_double_slit_process(coherence=0.01))
print(f'lab completion (n = 24, seed 7) at c = 0.01: divisible {lab["divisible"]}')

Up to c = 1/2 the fringes are there (visibility c), yet a valid slit-to-screen matrix exists: the process is divisible in Barandes's sense. It turns indivisible just above c = 1/2. Matched divisibility fails for every c > 0. The lab's own completion is already indivisible at c = 0.01.

Scanning real completions of this block form at c = 1/4, the symmetric slit pairs (3, 5) and (2, 6) admit a divisible completion, while the asymmetric pairs tried, (2, 5), (1, 4) and (1, 2), do not. So, in general, interference does not make a given completion indivisible. What it always does is break the composition through the process's own G(t2,t1). Which completions admit a stochastic middle step is not characterised here.

Summary¶

Property Decohered (c = 0) Coherent (c > 0)
Probabilities add yes no
Amplitudes add no yes
Interference pattern no yes
Matched divisible (abs(U2)^2 composes) yes no
Existential divisible (some valid G(t2,t1)), lab completions yes no
Fringe visibility 0 c

Every row of that table was computed on the same three matrices, with the lab's completion of U1. The existential row concerns the full transition matrix, and it depends on the completion: for the source column alone a valid G(t2,t1) always exists (section 6), and section 7's symmetric completion stays divisible up to c = 1/2 while showing fringes.

The interference pattern is the matched-divisibility defect. G(t2,t0) - G(t2,t1) G(t1,t0) is not merely correlated with the fringes; its source column equals them exactly. Summing over which-slit with the process's own slit-to-screen matrix is legitimate only when D = 0, and interference is what you get when it is not. Whether some other valid middle step exists is a separate question, answered by the LP, and its answer depends on the arbitrary completion.

Prior work: the fringe identity is Paper 1, eq. 43, where Barandes calls interference "a generic discrepancy" between the indivisible dynamics and a heuristic divisible one (§3.5); he does not claim that interference occurs if and only if a process is indivisible. See also LeBlond (arXiv:2511.02863). The existential/matched distinction follows Calvo (arXiv:2601.18720) and Doukas (arXiv:2602.22095).
